Papers and preprints

An Analytical Solution to the Generalized Belgian Chocolate Problem

This preprint characterizes the strong stabilization threshold for the generalized Belgian chocolate problem using harmonic measure and proves that no finite-order strictly stable controller attains it.

Regret Bounds for Fully Asynchronous Decentralized Multiplayer Bandits via Probing

This preprint introduces the lightweight probing algorithm PULSE and proves that it removes a √(log T) factor from the regret bound associated with permanent departures in fully asynchronous decentralized multiplayer bandits.
